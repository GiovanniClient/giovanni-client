# GiovanniClient
GiovanniClient is an opensource *QoL* mod for Hypixel Skyblock for modern minecraft versions. <br />
It is the spiritual successor to [ShadyAddonsReborn](https://github.com/GiovanniClient/ShadyAddonsReborn), which featured a small list of "innocent cheats".

## Core Features
- Rendering: many features such as NoFog, NoBlindness, NoOverlays...
- Inventory Buttons like [NEU](https://github.com/NotEnoughUpdates/NotEnoughUpdates/) had
- Auto Experiments and many such features
- Rift stuff
- (WIP) ESPs for blocks, Corpses in the Glacite Tunnels and much more :)

## Disclaimer
This mod provides *small* gameplay advantages. While designed to be pretty chill and not blatant, it's use-at-your-own-risk. The developers are not responsible for any moderation actions.
